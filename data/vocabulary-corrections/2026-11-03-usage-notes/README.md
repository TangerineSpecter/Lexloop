# 用法限制与剩余义项核验

基于 v1.27.163 的 10 项待补证与 1 项补义候选，本轮为 beard、arm、jaw、scream 追加四条用法说明，原义完整保留：俚语的特定语境、两个名词义的常用复数，以及 scream for 的短语结构。arm 的装备义、jaw 的狭窄范围及 scream 裸词配价/强度仍待核，不以局部改进掩盖未解决项。

breathing 的逼真义在 1908 年 Chambers 词典的 Breathe 条目派生形容词中取得依据；不据出版年代直接标为废弃，也不称现代常用。soft 的抽象名词方向由 Dictionary.com American noun 2 支持，保留原值。condom 的原值既有通用避孕套，又有合法的具体阴茎套义；美式与英式词典范围各有支持，不强制添加类型说明，本轮关闭该补义候选而非删除原义。

本轮后仍有 7 项待核：bone、twist、squeeze、quietly，以及部分补充了提示的 arm、jaw、scream。review.json 按词记录状态和 remainingConcern；状态为追加提示不等于完整审查通过。
