# 旅行场景英语

## 产品边界

「场景口语」面向希望在出国旅行中完成真实沟通的成人学习者，与现有词汇学习并行。首版使用文字角色扮演训练词汇、语法、句子组装、任务完成和自然表达；不根据文字推断发音、听力或真实口语流利度。

每次学习按 15 分钟设计：3 分钟准备常用表达和句子骨架、8 分钟完成 6–10 轮场景对话、4 分钟复盘并重说一句。当前场景覆盖机场、酒店、餐厅、购物、交通和求助六类，每类三个任务。

完成场景后，复盘页提供一条本次表达的可选改写练习：先写自己的版本，再对照保存的建议；若本次没有集中纠错，则用场景句型骨架试造一句。可以跳过或随时查看建议。练习只存在当前页面，不评分、不保存、不计入掌握或复习进度，也不发起新请求；切换复盘时草稿会清空。

## 水平测评

- 综合等级使用 CEFR A1–C1，同时保留分维度能力画像。
- 测评包含 20 道人工编写、版本化的客观题和 2 道自由表达题。客观题按当前估计等级调整出题顺序，但最终仍覆盖各级证据。
- 客观题由服务端确定正误；AI 只为自由表达返回结构化评分证据。AI 不可用时允许产生明确标记的临时评分，置信度不会标为高。
- 定级要求目标等级及所有前置等级达到 75% 门槛，并同时受自由表达等级约束；最终取两类证据中较低的等级。
- 测评可跳过；未测用户从暂定 A1 开始，场景完成后持续更新各维度分数。

## 场景与纠错

场景内容由稳定蓝图和 AI 变体组成。蓝图固定用户角色、AI 角色、沟通目标、回合边界、救命表达、句子骨架和 A1–C1 难度要求。AI 必须逐轮返回角色回复、目标完成状态、纠错、候选生词和分维度证据。

只有导致意思不清、事实相反或任务无法继续的错误会立即显示为阻断纠错；可理解的小语法问题、搭配和自然度问题不会打断对话。每轮回复后，学习者可自选展开已保存的补充提示，也可以跳过并继续对话；结算复盘仍会汇总相关表达。系统认可正常口语中的缩写、省略和短句，默认教授国际通用、礼貌且当代的表达。

## 数据和隐私

- 测评、能力档案、场景会话、逐轮输入、报告和每日计划都绑定当前用户。
- 最近的未完成场景可以由当前账号重新打开；读取不会创建会话或调用模型。没有收到回复的最后一句保留原消息 ID，供安全重试。
- 完成的场景复盘按完成时间倒序保存，可在场景地图分页浏览和重看反馈、句型及沟通目标。每页最多 10 份；详情和列表均按当前账号隔离。刷新或结算响应丢失后仍可找回报告。读取只返回已保存内容，不修改练习、能力或复习记录，也不调用模型；读取失败会显示重试入口，不当作“没有历史”。
- 用户输入先保存，AI 结构化回复验证后再写入；相同客户端消息 ID 不会重复生成回合。
- 场景日志与 AI 审计不额外复制完整私人对话内容。
- 场景 AI 使用独立每日回合配额，默认 40 次，可通过 `TRAVEL_SCENARIO_DAILY_LIMIT` 调整；Provider 或结构化输出失败会退回本次额度。
- 场景回合使用会话级处理令牌串行化，并以用户回合 ID 精确关联 AI 回复；并发提交不会越过回合上限，失败后可用原消息 ID 安全重试。
- 未完成正式测评的暂定用户会先练当前等级；两次稳定完成后进入高一级挑战，连续三次高一级场景达到语法、组句和任务门槛后上调暂定等级。正式等级仍只通过测评确认。
- `DELETE /api/v1/travel/records` 删除个人测评、场景、技能和每日计划记录；`DELETE /api/v1/vocabulary/personal` 删除旅行生词本。

## 后续语音阶段

语音阶段通过 API 预签名 URL 上传录音，由 Worker 异步执行转写、发音和韵律分析，再将发音、听力和流利度纳入能力画像。实现前必须增加录音授权、保存期限和主动删除策略。
