# 三种单词学习模式

## 1. AI 智能分组学习（闯关模式）

API 将本次新词与复习词先随机打乱，再按每组 2–5 个词动态分组；每组对应一篇阅读材料和组内练习。学习序列按服务端保存的分组索引和完成状态展示当前进度，完成当前组后进入下一组。

- 节奏受学习序列约束，完成本组新词和复习后解锁下一组。
- 每组提供拼写和阅读语境练习，用于强化记忆。
- 适合需要完整、稳定刷完词书的学习者，例如考研、雅思或 GRE 长线计划。

## 2. 独立单词学习（自由刷词）

单词没有分组或解锁顺序。每个词单独成一组。学习者按来源选词，而不是把当天的复习词和新词原样拆成一词一组。

创建时在 `POST /study/plans` 上传 `mode: "individual"` 和 `selection`：

- `book`：按默认词书顺序取还没学过的词。
- `mistakes`：从错题本里待巩固、且尚未掌握的词开刷。
- `random`：从默认词书尚未掌握的词里随机抽取。
- `frequent`：优先已学次数、口语优先度和较低 CEFR；词表没有这些标记时取词书前部。

每次 1–20 个词。适合碎片时间学习和定向复习。

## 3. 应试语境（原创题型训练）

应试语境仍是一份普通 `StudyPlan`，模式为 `exam`。它使用当天的复习词和新词，但换成应试提示词，并按固定配比指定题型：词义识别（熟词僻义）约 40%，单词匹配（固定搭配）约 30%，同义替换约 20%，阅读理解约 10%。不使用单词助记。

材料必须由模型原创。不引用、改写或仿写历年真题原卷。适合想在阅读和完形语境里巩固熟词僻义与搭配的学习者。

## 薄弱词专项

客观题答错后，系统按“单词 × 题型”创建或更新薄弱项。用户可在「待巩固」中筛选、查看原题、暂时忽略，并从系统推荐的薄弱词中调整 1–20 个生成专项。每个单词采用当前最优先的薄弱题型生成新语境和新选项；专项作答继续更新正常复习排期。同一薄弱维度连续答对两次后转为「已纠正」，但不会自动标记单词为「已掌握」。

薄弱项状态调整与新作答同时发生时，服务端只接受基于当前状态和作答计数的更新；若状态已变化，会提示刷新后重试，不用陈旧请求覆盖新答题结果。

答错后，下次复习安排在服务器记录错误的 24 小时后，不代表一定落在下一个本地日历日；结算页显示当前保存的具体时间和设备时区。不同计划或练习模式同时提交同一账号的同一词条时，系统按已保存的前序作答更新排期。历史排期不会因算法调整自动迁移。

普通计划与薄弱词专项分别只保留一个未完成计划，二者可以同时存在。专项内容仍经过服务端结构校验与公共缓存，但缓存签名包含计划用途和目标题型，不能与普通计划混用。

## 上下文学习助手

正式生成的学习分组和错题详情提供独立 AI 会话。学习分组未提交时，服务端不会把正确答案、解析或匹配关系发送给模型，助手只能逐步提示；提交后可解释答案与干扰项。会话按分组或薄弱项保存，可加载更早消息、清空当前会话并重试失败回答；每日提问额度默认 30 次，Provider 失败不消耗额度，错误会以不泄露密钥的中文提示引导用户检查模型设置。

生成分组练习侧栏默认只显示英文词条；需要提示时可逐词展开中文释义。提示状态只存在于当前页面，不改变判分、答案揭示门槛、复习排期或服务端记录；侧栏不再把无操作的整行伪装成按钮。

## 当前页面行为

创建计划后先进入预习；开始挑战会把计划写入当前学习序列。分组模式的“继续学习”进入本组阅读材料和练习页。单词匹配题选中顶部英文短语后，可按 `1`–`4` 将其插入对应序号的中文释义槽；快捷键编号不显示在界面上。插入后，释义槽只显示英文短语，顶部对应短语置灰并禁用，不能重复选择。鼠标点击释义槽与快捷键具有相同效果；输入框、文本域等编辑控件内不响应快捷键。每个释义槽同时显示简短 Tips，只补充释义侧重的语义方向，不泄露短语或正确答案。提交后立即反馈：错误释义保留已选短语并划线标记，旁边同步展示正确短语；正确项显示绿色，错误项显示红色。同义替换题提供可替换原词的英文正确候选与语义相关但不可替换的英文干扰项，不展示中文释义。所有选择题在作答后立即显示正误、正确答案和中文解析。完成本组并提交结果后，页面进入本组结算：汇总单词数、正确率、题型结果、后续复习节奏和需要巩固的单词；结算页只展示已提交结果，不额外修改服务端排期。学习统计只记录单词学习产出：本期完成单词数、词汇积累、新学词、复习词和掌握词；“学习节奏”按每天完成的新学与复习单词数展示。30 天打卡网格使用紧凑尺寸；每个打卡格与柱图一样，鼠标悬停或键盘聚焦时会上浮并显示当天单词数。计划、分组、阅读材料、题目、作答与错题状态均通过 API 持久化；AI 内容当前由 API 生成并写入公共内容缓存。

分组阅读只高亮与目标词完整匹配的英文词项（不区分大小写），不会把 `bright` 误标为 `brightness` 或 `brightly` 中的字母片段。复合词和词形变化仍按不同词项处理。

分组阅读的全文和逐句朗读会优先选择浏览器提供的英语语音。若浏览器不支持语音合成或当前没有可用的英语语音，原文仍可直接阅读；离开当前分组或收起分句阅读时会停止旧朗读。语音由浏览器的 SpeechSynthesis 提供，具体声音取决于设备和浏览器设置，不保证离线合成。

“当前学习序列”和“今日学习历史”依赖已保存计划列表。列表读取失败时显示可重试状态，不将失败伪装成空记录；读取成功前暂停创建普通计划，避免用户在现有计划未确认时重复开始。创建请求未完成时按钮会显示等待状态并禁止重复提交；失败后可以重试，同一账号的并发创建请求由 API 串行检查并复用已创建计划。

切换默认词表后，词汇列表会随当前词表重新加载；加载中或失败时不会展示上一词表的单词，也不能据此创建计划。加载失败可在列表处重试，过期的词汇请求不会覆盖当前词表结果。

关闭计划预习只关闭当前弹窗，不取消或删除服务器上的生成任务。生成响应迟到时只更新对应计划记录；如果用户已关闭弹窗、打开了另一个计划或切换账号，迟到结果不会重开或替换当前界面。生成失败后会重新读取计划状态，刷新或重新进入时仍以服务器保存结果为准。
