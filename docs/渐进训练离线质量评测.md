# 渐进训练离线质量评测 v1

这是可重复的程序防护评测，不是模型质量、CEFR 难度或学习效果认证。样本来自项目自写的三组虚构练习，未复制真题、外部阅读篇章或词典。运行时不调用模型、不联网。

## 重现

在 `apps/api` 执行 `pnpm exec vitest run test/progressive-quality.spec.ts test/progressive-practice.spec.ts`；完整数据库回归使用仓库根目录的 `node scripts/test-api-isolated.mjs`。样本为 `test/fixtures/progressive-quality-samples.ts`，反例和预期由固定测试表给出，不用第二个模型评分。

12 个固定探针包括：三个阶段各一个基线；单项多句、基础重复句、迁移重复句、混入中文共四个反例；头衔、缩写、小数、引号四个正常边界；一个结构合法但预设答案明显错误的语义盲区样本。另有连续返回不合格材料时最多修复 3 次的测试。

## 已自动化的防护

- FOUNDATION/CONTEXT 的每个目标句分别检查长度；TRANSFER 检查 35–55 词及三项材料，题型和目标词覆盖继续沿用校验。
- 渐进材料的英文栏必须含英文字母且不混入中文汉字。
- 每项按英文句界分段后应只有一句。使用运行时英文 `Intl.Segmenter`，先保护常见头衔与带点缩写；不是通过句号数量猜句数。小数、分号和引号边界有固定正例。
- 忽略大小写、标点及空白后相同的句子不能用于凑阶段句数。
- 失败进入既有有限整组修复；生成与公共缓存读取共用校验。隔离 PostgreSQL 测试覆盖长度、合并句和重复句三种坏缓存，只替换失败组，保留其他组及学习证据。

句界算法是有边界的结构启发式，不是完整英语语法分析器；少见缩写、姓名首字母或复杂引用可能需要复核。重复检查只针对文本相同，不能识别语义重复。不能将该小样本探针的通过率外推为真实生成合格率。

## 内容评审清单

对每组材料保存原始输出、阶段、词条词性与当前词书义项，然后独立记录以下项目，不能用一个总分掩盖问题：

| 项目       | FOUNDATION                   | CONTEXT                                | TRANSFER                                                           |
| ---------- | ---------------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| 词义与词性 | 目标词是否使用输入义项与词性 | 替换词能否直接代入，词性/搭配是否保持  | 文中目标词的义项是否与输入一致                                     |
| 证据       | 答案是否能从直白语境得到     | 人物、动作或时间线索是否足以排除干扰项 | 至少两个不同句子的线索是否共同必需；移除其中一个后推理是否不再充分 |
| 干扰项     | 粒度是否相近且只有一个正确项 | 错项是否有合理关联但不能替换           | 是否只有一个由全文支持的答案，无需外部常识补足                     |
| 阅读负担   | 周边词与句式是否常见简单     | 难度是否来自用法而非生僻周边词         | 难度是否来自跨句整合，而非多义歧义或坏语法                         |
| 解释       | 是否明确指出实际线索         | 是否说明替换保持与改变了什么           | 是否明确引用各句证据及推理关系                                     |

这些评审项目本轮没有自动判断，也没有完成真实模型抽样验证。固定的 `semantic-blind-spot` 样本把“可用的”答案改成“昂贵的”，仍通过结构校验；测试明确保留这一盲区，避免把字数、题型合规误报成语义正确。
