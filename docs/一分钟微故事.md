# 一分钟微故事

入口为 `/dashboard/micro-stories`，首页学习专项和侧栏均可进入。目标是让用户在零散时间里完成一段连续场景阅读，并留下真实理解偏差。

## 学习流程

每段为 2–3 句，按上班路上、咖啡店、开会之前三个连续场景排列，从 A1 到 A2 共九段。当前内容为内置、人工审核的首批试用内容，不依赖模型或后台生成；`key` 一经发布不能指向不同原文，否则已保存的偏差卡会失去上下文。

用户先阅读并输入自己的中文理解，API 保存输入后才返回参考意思、容易误解的用法和一个可替换句型。用户自行判断理解是否有偏差；标记偏差后，原文、自己的解释及可选造句写入个人偏差卡。服务端不会声称自动判断翻译对错。完成一段后自动接到下一段，进度按账号保存。

英文原文与到期复习句提供正常速度和 0.8 倍慢速播放，方便听辨并跟读。播放使用浏览器原生语音合成，优先选用英语语音；音频不上传、不保存，也不依赖 AI。浏览器不支持语音合成时，页面保留阅读和跟读流程并提示当前限制。

偏差卡按 `APP_TIMEZONE`（默认 Asia/Shanghai）在次日 06:00 到期。用户先回忆原句，再展开上次理解与参考解释，选择“想起来了”或“还没记住”。记住后的间隔为第 3、7、14、30 个本地日历日的 06:00；没记住则次日 06:00 再看。页面每次只取一张到期卡，降低碎片时间的操作量。每段完成写入 `MICRO_STORY_COMPLETED` 学习事件，计入活跃日，但不推定词汇掌握或 CEFR 等级。

偏差本按需读取当前账号最近 20 条记录，保留原文、自己的解释、参考意思和差异说明；默认折叠，避免挤占一分钟阅读区。

## 数据与边界

`MicroProgress` 保存已完成故事 key 和正在理解的故事 key，内容重排或新增不会误认用户进度；`MicroError` 以账号和故事 key 唯一保存偏差、造句与到期时间。所有读写使用 JWT 用户作用域；提交理解与完成段落和“清理全部学习记录”共用用户事务锁。清理同时移除进度与偏差卡。Web 仅通过 API 访问这些数据。展开中的偏差本在完成故事或复习后同步刷新。

首批内容读完后页面仍能复习到期偏差。下一轮可扩展更多人工审校的内容或增加分级内容管道；当前九段不构成完整的英语课程。
