# 一分钟微故事

入口为 `/dashboard/micro-stories`，首页学习专项和侧栏均可进入。目标是让用户在零散时间里完成一段连续场景阅读，并留下真实理解偏差。

## 学习流程

每段为 2–3 句，包含上班路上、咖啡店、开会之前、周末约朋友、家里维修、项目改期、单车维修、超市补货和归还图书九组成人日常场景，共二十七段。内容标注 A1、A2、B1 作为宽泛练习分组，不代表严格递增，也未经过 CEFR 专业认证。原有二十一段的 key 与顺序不变；本批在单车维修故事之后新增“超市补货”和“归还图书”各三段，目录暂将这六段列在 B1 练习组。独立复核认为超市第 1、3 段更接近 A2 至较低 B1，图书第 2、3 段更符合 B1；目录顺序不表示难度递增。超市故事从发现米已用完、询问库存到等补货后再购买；图书故事从续借一本书、另一册因有人预约而不能续借，到归还被预约的书。本批新增故事为原创，已完成独立内容复核；这不是专业语言认证。当前内容是内置试用材料，不依赖模型或后台生成，也不代表真题；`key` 一经发布不能指向不同原文，否则已保存的偏差卡会失去上下文。

用户可先听后看或直接阅读，并输入自己的中文理解；API 保存输入后才返回参考意思、容易误解的用法和一个可替换句型。用户自行判断理解是否有偏差；标记偏差后，原文、自己的解释及可选造句写入个人偏差卡。服务端不会声称自动判断翻译对错。默认按目录顺序继续；尚未开始当前理解时，也可以按宽泛练习分组浏览并选一段未完成故事。选择只保存当前故事 key，不算完成；查看解释后、输入理解或英文尝试后暂不允许切换，完成后回到默认顺序中的下一段。切换请求等待服务端结果期间，选择窗口保持打开以防输入落到背景页；离开页面后重新进入时按服务端状态读取。已完成故事仍通过单独的重读列表访问。

查看解析后，可选把本段人工选定的重点表达连同语境义和原文收藏到个人生词本；表单可编辑，收藏后沿用生词本现有的动态复习安排。后续复习提交答案后，反馈和历史逐题回顾会带回收藏时的场景与原句，答案提交前不会展示原句。这个操作不会改变微故事进度、首次理解或偏差卡；答案揭晓前接口不返回重点表达，重读已完成故事也只开放给该账号本人。

未完成故事的中文理解和可选英文尝试保存在当前浏览器，并按账号与故事段分别恢复；若服务端已经保存了理解，以服务端版本为准。旧版只保存一个故事草稿的记录会在打开对应故事时迁移。完成故事后清除该段草稿，输入区也提供清除本机草稿的操作。草稿只保存在当前浏览器；未提交内容不会跨设备同步。其他标签页改变当前故事时，本页会按服务端状态刷新，但本机已保存的各段草稿仍分别保留；如果未提交输入因存储不可用而只在页面内存中，本页会暂缓自动切换以避免覆盖，提示先复制或清除输入再重新读取。到期复习可先用自己的话重写再查看旧记录，也可明确选择跳过本次回想；本次回想只保存在当前浏览器，不会跨设备同步。刷新后仍可继续，失败的复习请求不会清除它；用户可在揭示前清除本机回想草稿。成功复习或清理全部学习记录后清除对应草稿。浏览器存储不可用时，当前页面仍可继续学习，但刷新后无法恢复草稿。

复习草稿按账号、卡片和服务端到期时间区分轮次。若提交结果暂时未知，当前轮草稿会保留；当服务端显示卡片已进入下一轮时，上一轮答案不会自动带回新的主动回想。升级前未记录轮次的旧版本机草稿仍会保留，但需要用户明确选择恢复或清除。

英文原文可选“先听后看”：收起文字但保留正常速度和 0.8 倍慢速播放，用户先写下听懂的意思，也可选写一句英文复述，再查看原文和解释。自己的英文尝试会与参考句型并列展示，不做自动评分；标记理解偏差时仍可按原流程保存到复习卡。当前故事还提供可选口语跟读：用户主动授权麦克风后，可录制最多 30 秒并回放自己的表达，与原句对照。录音只保留在当前页面内存中；取消、删除、切换故事或离开页面会释放音轨并清除临时音频，不写入浏览器存储、不上传、不转写、不评分。拒绝权限或浏览器不支持录音时，原有播放和文字复述仍可使用。到期复习句同样提供正常与慢速播放，方便听辨并跟读。原文播放只选择浏览器标记为本地服务的英语语音；没有此类语音时，页面提示后仍可直接阅读。文本不会发送到 Lexloop API；语音由浏览器和设备提供，本功能不保证整个设备处于离线状态。浏览器不支持语音合成时，页面保留阅读流程并提示当前限制。

偏差卡按 `APP_TIMEZONE`（默认 Asia/Shanghai）在次日 06:00 到期。用户重新写下句意后再查看上次理解与参考解释，并自行选择“想起来了”或“还没记住”；页面不比较答案或自动评分。记住后的间隔为第 3、7、14、30 个本地日历日的 06:00；没记住则次日 06:00 再看。页面每次只取一张到期卡，降低碎片时间的操作量。每段完成写入 `MICRO_STORY_COMPLETED` 学习事件，计入活跃日，但不推定词汇掌握或 CEFR 等级。

偏差本按需读取当前账号最近 20 条记录，保留原文、自己的解释、参考意思和差异说明；默认折叠，避免挤占一分钟阅读区。已完成故事也可按需重读：列表只返回本人已完成段落的英文与标题，解析需单独请求；用户可先写下这次回想，也可明确跳过。回读答案只在当前页面显示，不保存回想、不写学习事件，也不改变原进度、首次理解、偏差卡或复习排期。

## 数据与边界

`MicroProgress` 保存已完成故事 key、当前故事 key 和当前理解；仅选择故事会写入当前 key 并将理解留空，不创建学习事件或完成记录。切换请求带上页面看到的当前 key，在用户事务锁内比较，避免过期标签覆盖较新的选择。已有服务端理解时不允许切换，完成后清空选择并恢复目录默认顺序。`MicroError` 以账号和故事 key 唯一保存偏差、造句与到期时间。所有读写使用 JWT 用户作用域；提交理解与完成段落和“清理全部学习记录”共用用户事务锁。清理同时移除进度与偏差卡。Web 仅通过 API 访问这些数据。展开中的偏差本在完成故事或复习后同步刷新。

二十七段内容读完后页面仍能复习到期偏差或重读已完成故事。后续可继续扩展经内容复核的故事或增加分级内容管道；当前二十七段不构成完整的英语课程。
