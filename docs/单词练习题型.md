# 单词练习题型说明

本文定义 Lexloop 的练习题型、作答交互与反馈方式。题型可以被 AI 智能分组学习、独立单词学习和应试语境复用；一次练习可围绕一个目标单词、一个单词组或一篇阅读材料生成。当前应试语境只使用原创练习，不读取真题原卷；真题题库尚未实现。

## 题型分类与判分

| 分类       | 题型                                             | 作答方式             | 反馈方式                               |
| ---------- | ------------------------------------------------ | -------------------- | -------------------------------------- |
| 客观选择题 | 单词助记、词义识别、单词匹配、同义替换、阅读理解 | 选择或连线           | 系统自动判分，并展示答案与解析         |
| 主观输出题 | 句子翻译、主题造句、句子改写                     | 手写输入             | AI 按评分要点批改，并给出修改建议      |
| 专项巩固题 | 单词拼写、听力练习、口语练习                     | 拼写、听辨选择或朗读 | 拼写与选择自动判分；口语由 AI 评估发音 |

客观题应在提交后立即返回正误、正确答案和简明解析。主观题应保留用户原始作答，并返回总评、核心得分点、可改进之处和参考答案；AI 反馈不应只给出笼统评价。所有作答均应记录为学习事件，供错题复习和学习报告使用。

### 客观题统一呈现与反馈

- 题干默认使用自然英文；目标词在题干或语境中高亮。阅读材料可继续提供中文翻译、简化文本和语法辅助，但不替代英文题目。
- 词义识别与单词匹配的释义区使用中文，以考查英语语境到中文义项的理解；单词助记、同义替换和阅读理解的候选项使用英文，不展示中文释义。
- 单选题点击选项后立即锁定并反馈；多选题和匹配题点击各自的提交按钮后立即反馈。选中的正确项为绿色，选中的错误项为红色；遗漏的正确项须明确标为“漏选”，错误单选和多选同时标出正确项。
- 所有选择题反馈固定先展示“正确答案”，再展示中文“题目解析”。解析必须说明语境或构词依据；有干扰项时说明其为何不符合当前题目。

## 一、客观选择题

### 1. 单词助记（多选题）

**题目形式**：使用英文题干给出目标单词，并展示词根、词缀、形近词、派生词等英文关联词汇。学习者从 4 个英文候选项中选出与目标词相关的词。

**考查重点**：词源、构词关系与词形辨析。

**适用价值**：帮助学习者一次性建立同源词网络，适合大学英语四、六级和考研的扩展记忆。

**判分规则**：仅当选中全部正确项且未选错误项时判为正确；反馈中应说明每个选项与目标词的关系，例如词根关联、派生关系或仅为形近干扰项。

### 2. 词义识别（单选题）

**题目形式**：给出包含并高亮目标词的完整英文语境，并提供 4 个中文释义，学习者选出该语境中的准确义项。

**选项设计**：4 个选项必须都是合理且容易混淆的中文词义，优先取自同一英文词的不同常见义项；例如 `order` 在“订票”语境中考查“订单”，干扰项可以是“规则、顺序、命令”。当目标词义项不足 4 个时，可使用词性相近、语义邻近或同一语境下常被误判的中文概念补足，但不得使用明显无关的选项。选项应尽量保持词性和表达粒度一致，避免靠字数或语体差异排除。

**考查重点**：基础认词与高频词义识别。一词多义时，优先考查阅读中常见的词义，并在解析中标明本题所考义项。

**适用价值**：快速判断学习者是否真正认识该单词，为后续复习提供基础数据。

**判分规则**：只接受当前语境对应的一个义项。反馈应指出正确义项在句中的依据，并说明其他选项虽可能是该词的其他义项或相近概念，但为什么不符合此处语境。

### 3. 单词匹配（匹配题）

**题目形式**：用英文指令说明配对任务，围绕一个目标词给出 4 个英文短语或固定搭配，以及 4 条对应的中文功能/语义描述；学习者完成一一配对。

**出题逻辑**：4 个短语应使用同一目标词，但分别考查不同搭配、不同句法位置或不同语义侧重。中文描述应说明短语在何种场景、用途或语义维度下使用，并处于相近语义场以形成真实混淆；每条描述必须只对应一个短语。Tips 只补充描述强调的维度（如“侧重使用场景”“侧重物理状态”），不能出现候选短语、目标搭配的关键词或足以直接推出答案的信息。

**考查重点**：同一目标词在不同固定搭配中的含义与用法差异。

**适用价值**：适合围绕词表进行批量巩固。

**交互与判分规则**：学习者点击英文短语，再点击中文释义槽，或在选中短语后按 `1`–`4` 插入对应序号的释义槽。界面不展示快捷键编号；插入后槽位只显示英文短语，且顶部对应短语立即置灰禁用，不能重复选择。每一对独立判断；反馈保留学习者选中的短语并展示正确短语，帮助定位具体混淆的搭配。

### 4. 同义替换（单选题）

**题目形式**：给出包含并标出目标单词的英文句子；从 4 个纯英文候选中选出可替换该词且不改变句意的同义词或近义表达，不展示中文释义。

**选项设计**：正确项必须在当前句子的词义、词性、数和搭配上都可直接替换。其余 3 项应是有迷惑性的干扰项：可以与目标词处于同一语义场、是相关概念、属于目标词的另一义项，或词义接近但在当前句子中词性、范围、语气或搭配不成立；不得放入明显无关的词。每个候选可附简短英文释义，帮助学习者理解候选本身，但释义不能直接标注正误或泄露正确项。

**考查重点**：单词在具体语境中的词义、词性和搭配限制。

**适用价值**：帮助学习者掌握阅读和完形填空中的语境辨义能力。

**判分规则**：仅正确项得分。反馈应说明正确项为何能保持原句语义，并逐项指出干扰项因词义、词性、范围、语气或搭配不符而不能替换的原因。

### 5. 阅读理解（单选题）

**题目形式**：提供 AI 生成短文或合规使用的四、六级真题原文；文中高亮本次背诵的单词，并根据文章细节、词义或主旨设置英文单选题。题干和 4 个选项均为英文，不展示中文释义。

**考查重点**：在真实篇章中理解目标词，并训练定位信息、推断词义和概括主旨的能力。

**适用价值**：把单词记忆连接到阅读做题能力。

**内容要求**：AI 生成内容须与目标词难度、学习阶段和考试场景匹配。使用真题时须确认内容来源与版权使用方式；文段、题目和解析应一一对应。

## 二、主观输出题

### 1. 句子翻译

**题目形式**：给出包含目标单词的英文句子，学习者手动输入中文翻译。

**考查重点**：目标词词义、句子主干、语序和关键语法结构的理解。

**AI 批改要点**：核对核心单词是否译准、句子关系是否表达完整、译文是否通顺。允许合理的同义翻译，不应机械要求与参考答案逐字一致。

**适用价值**：提升单词在句子中的翻译能力，并为翻译与写作打基础。

### 2. 主题造句

**题目形式**：给定目标单词和话题（如校园、职场、考试），学习者写出一句包含该单词的英文句子。

**考查重点**：拼写、词形、词性、搭配、语法正确性，以及句子是否契合主题。

**AI 批改要点**：检查目标词是否被正确使用，指出语法或搭配错误，提供可直接对照的优化示例；表达自然且语义合理时应给予正向确认。

**适用价值**：促成主动运用，解决“认识但不会写”的问题。

### 3. 句子改写

**题目形式**：给出含目标词的原句，要求使用指定同义词或指定句式改写整句，并保持原意。

**考查重点**：同义表达、句式转换、时态与语义等价。

**AI 批改要点**：分别判断语义是否保留、指定表达是否正确使用、语法是否正确。若改写改变了原句的肯定否定、时态、程度或逻辑关系，应明确指出。

**适用价值**：积累可迁移的写作表达，提升改写与写作得分能力。

分组阅读另提供可选的目标词造句：学习者选择本组词，在自己的生活或想法中写一句英文，再按需查看词义/用法、语法和自然度建议。内容只有主动提交后才发送给当前选择的模型；这是形成性参考，不是统一主观题批改，不给分、不声明掌握，也不进入作答或复习记录。失败时原句留在当前页面，可主动重试。

分句阅读还可先用中文写下自己对英文原句的理解，再查看模型对核心意思和中文表达的参考建议，并对照材料中的一种参考译文。也可以跳过输入直接查看参考译文；不同译法不要求逐字一致。只有主动提交后，英文原句和学习者译文才发送给当前选择的模型；不计分、不保存、不改变复习安排，失败时保留当前页面里的输入以便重试。

学习材料生成校验会拒绝未支持的题型，以及在忽略大小写、连续空白和 Unicode 兼容宽度后仍重复的单词匹配短语或释义；匹配提示里的完整配对短语也会在同样规范化后检查，避免直接泄露答案。题干必须是英文，除词义识别外的选项不能夹带中文提示；助记多选题的正确选项不能重复，否则学习者无法按唯一选项集合完成作答。匹配题只使用配对内容，冗余选项和答案列表不会发送给未提交练习的学习者。旧缓存中的多余选项在未提交响应中也会清空，无效缓存不会提供给学习者。这些检查只验证结构和明显的直接提示，不证明题目或解析在语义上正确。

同一原句或目标词与答案再次请求建议时，最近一次成功反馈会在更新期间继续显示；若这次失败，旧反馈和原输入仍保留。编辑答案后，只展示与当前答案匹配的反馈，避免旧建议看起来像是针对新表达。

这两种可选反馈按不同维度给建议，不互相替代：改写的 `meaning` 对照人物/动作、肯否、时态、程度和因果等核心关系；`grammar` 只说明明确的语法结构或词形问题；`naturalness` 只说明搭配、惯用表达或语域。目标词造句的 `wordUse` 按给定义项、词性、合适词形和搭配判断，`meaning` 说明整句是否表达清楚并符合给定词义，语法和自然度仍分别说明。合理同义表达不因未照抄参考句而被判错；没有明显问题时应明确肯定，不强行纠错。可选参考表达应保留原句/学习者想表达的意思以及目标词用法；没有必要时留空。以上反馈始终是当前练习的形成性参考，不构成分数、CEFR 判断、掌握记录或复习依据。

## 三、专项巩固题型

### 1. 单词拼写练习

**题目形式**：播放目标单词发音，仅展示中文释义；学习者手动拼写完整英文单词。当前生词本练习只选择浏览器标记为本地服务的英语语音；没有此类语音时可直接显示答案。文本不会发送到 Lexloop API，但本功能不保证整个设备处于离线状态。

**考查重点**：听音、词义到拼写的双向提取。

**适用价值**：解决“会认不会写”，服务写作和单词填空。

**判分规则**：忽略非实质性的首尾空格；拼写必须与目标词及题目要求的词形一致。拼错时应突出错误字符，并展示完整正确拼写和音标或发音入口。

### 2. 听力练习

**题目形式**：AI 朗读单词或短句，学习者根据音频选择对应释义，或拼写听到的单词。

**考查重点**：纯听觉条件下的辨词与语境理解。

**适用价值**：训练英语听力中的词汇识别，适配四、六级听力备考。

**交互要求**：题目默认不展示可直接泄露答案的英文文本；可提供有限次数的重播，并记录重播次数用于学习分析。

### 3. 口语练习

**题目形式**：展示单词或句子，学习者跟读并提交录音；AI 对发音进行识别与评估。

**考查重点**：发音准确度、重音、音素和句子节奏。

**适用价值**：纠正单词发音，支持口语备考与日常表达。

**AI 反馈要求**：返回整体准确度和可操作的改进建议；对于单词，至少标出重音或易错音素；对于句子，可补充连读、停顿和语调建议。录音、转写和评分应在获得用户授权后处理，并遵循隐私与存储策略。

## 题型编排建议

- 新词首次学习可优先使用词义识别、单词助记和单词匹配，建立词义与词形连接。
- 巩固阶段可使用拼写、同义替换和句子翻译，验证是否能准确提取与理解。
- 熟练阶段可加入主题造句、句子改写、阅读理解、听力和口语，检验迁移与输出能力。
- 错题复习应优先重出同一能力维度的题目，并可切换题型验证是否真正掌握，避免仅记住答案。
- 当前错题本按“单词 × 题型”维护薄弱项；专项首题固定使用原错误题型的新变式。同一维度连续答对两次后视为已纠正，之后可再通过其他题型验证迁移能力。

## 实现边界

- Web 负责展示题目、采集选择、文本和录音输入，并通过 API 提交需要持久化的作答；不直接调用 AI Provider 或访问学习数据存储。当前生词本听音拼写只在页面内对照，不提交 API、不保存成绩或复习证据。
- API 负责题目、答案、评分结果和学习事件的校验、持久化与查询。
- 阅读材料、主观题批改、语音识别与口语评分等耗时 AI 任务应由 Worker 异步处理；前端通过 API 获取任务状态和最终反馈。
- 题目生成应包含目标词、考查义项、难度、题型、标准答案、解析与评分要点，便于可追溯地判分和复习。
