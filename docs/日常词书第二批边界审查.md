## 实际修正

在 v1 已修正的五行之外，逐项检查源文件前部的 72 个多词单元格及邻近主题：36 行确认是词列，7 行保留为正常短语/搭配，29 行存在内部短语或疑似转录问题而保留。审查由助手完成，不冒称专业人工审校；结论与理由逐行保存在 `daily-vocabulary-boundary-review.json`。

新增 36 行展开为 92 个原拼写词面；连同原五行，累计 41 行展开为 109 词。新装日常词书由 v1 的 1,189 条变为 v2 的 **1,245 条**，净增 56 条，不含重复词面。释义与音标新增数均为 **0**。拆分行原有的三项字段都必须为空或“无”，否则拒绝导入该书，不丢弃现有内容。

例如 `surname nickname` → `surname / nickname`，`shoulder arm elbow` → `shoulder / arm / elbow`，`breathe breath breathing` → `breathe / breath / breathing`。保留 `human body`、`skin cell`、`mental stress`；`thumb finger nail`、`soap bar towel` 有内部词组边界问题，`hip waste leg`、`curly strait`、`wait gain` 有疑似转录问题，均不猜改。

1,096 个原始多词行的当前分类：旧修复 5、新明确词列 36、保留短语 7、歧义 29、尚未审查 **1,019**。另外 81 个单词面单元格仅标为单元格格式，不据此认定拼写或词义正确。这不是剩余全书已经审校完毕。

## 已有安装的可行方案与当前边界

v2 修订号是 `daily-boundaries-2026-11-03-v2`。新书在同一事务内发布完整关联；既有 NULL 或 v1 修订保持原样，不改版本号、不移动位置、不删除关联、不复制掌握度。真实临时数据库测试从实际 v1 的 1,189 条映射和学习记录开始，并发运行 v2 后快照完全相同；反向运行 v1 导入也不会改写新建 v2 书。旧版不识别 revision 的混合并发屏障继续回归。

**本次已有安装实际转换数为 0。** 禁止删除旧书或手工抬高 revision 强行触发修订。只有新装/此前没有该书的安装会直接采用 1,245 条映射。

后续对旧安装优先采用明确选择的“修订伴随词书”，而不是在原书原位拆词：

1. 只读预览先校验 SYSTEM、无 owner、sourceKey、旧 revision 和完整 position→normalized 映射；不匹配或用户修改项逐条报告，不能按行号猜测关联。
2. 只纳入已核验且有可用释义的修订目标词；缺释义词不得包装成可练内容。列出每个旧词条 ID、候选词面、现有全局词条与字段来源、已有掌握记录，以及保留/新增的具体数量；目前尚无来源质量核验足够的全量伴随词书。
3. 经用户明确选择后，新建独立 sourceKey/revision 的 SYSTEM 伴随词书，原书及其 bookWordId、历史题目快照和排期完全保留。订阅与默认词书切换需要用户选择；不自动复制答题次数、SRS 或掌握状态，不把“旧串答对”解释为每个新词都已掌握。
4. 应用必须具备预览令牌/完整映射哈希、事务、幂等标识及审计记录；关联或个人字段在预览后变化则冲突退出。发布前覆盖并发导入、重复应用及中途失败回滚。
5. 尚无学习记录的新伴随关联可按批次恢复；一旦有学习记录，应停用/取消默认订阅而保留关联与记录，禁止强删“回滚”。

这个方案可保留旧进度，又不捏造新词能力，但会产生独立的学习路径。因此本批仅交付可复核的位置映射与保护测试，没有把尚未实现的伴随书流程宣传为现成功能，更没有对生产执行 apply/restore。
