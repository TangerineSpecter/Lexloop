# 三种单词学习模式

## 1. AI 智能分组学习（闯关模式）

系统将当天的新词按固定上限切分为小组；当前实现的展示分组上限为 3 词，后续应由 API 的学习策略返回实际分组。一组单词对应一篇阅读材料和组内练习，完成当前组后才能进入下一组。

- 节奏受学习序列约束，完成本组新词和复习后解锁下一组。
- 每组提供拼写和阅读语境练习，用于强化记忆。
- 适合需要完整、稳定刷完词书的学习者，例如考研、雅思或 GRE 长线计划。

## 2. 独立单词学习（自由刷词）

单词没有分组或解锁顺序。学习者可以自由挑选、随机学习，或只处理错词、生词和高频词。

- 支持碎片时间学习与定向复习。
- 可承载自建词表和导入单词。
- 适合时间不固定、需要查漏补缺的学习者。

## 3. 真题模式（应试专项）

单词围绕历年考试真题语境组织，生成阅读理解、单选、翻译、同义替换等题型。

- 强调熟词僻义、固定搭配和真题语境。
- 学习目标直接服务于考试提分，并形成专属备考路线。
- 适合雅思、托福、考研英语等短期冲刺和刷题备考。

## 当前页面行为

创建计划后先进入预习；开始挑战会把计划写入当前学习序列。分组模式的“继续学习”进入本组阅读材料和练习页。当前前端以本地存储保留演示进度；正式接入时，计划、分组、阅读材料、题目和作答事件必须通过 API 读写，由 Worker 异步生成 AI 内容。
