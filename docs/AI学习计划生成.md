# AI 学习计划生成

## 生成流程

1. 用户在“阅读材料模型”中明确选择管理员已启用的模型。
2. `POST /study/plans` 原子性选取今天到期的复习词与当前新词，返回 `GENERATING` 计划。
3. Web 立即打开预习层并展示“学习计划生成中”，开始挑战按钮保持禁用。
4. Web 调用 `POST /study/plans/:id/generate`。API 先原子性领取生成任务；同一计划的其他并发请求只读取状态，不会重复调用模型。
5. API 使用用户所选模型生成结构化 JSON，校验分组、目标词、逐句翻译与逐词题目。只有校验和持久化全部成功后，新词才进入学习进度。
6. 校验成功后计划进入 `ACTIVE`；失败进入 `FAILED` 并保存错误摘要，用户可在预习层或学习历史中重试。生成锁超过 10 分钟可被重新领取，避免进程异常后永久卡住。

真题模式不调用 AI，目前明确提示功能建设中。

## 分组规则

- 独立单词：一个单词一组；10 个词对应 10 篇短材料。
- 分组学习：先随机打乱，再按 2–5 个词分组，避免末尾只剩 1 个词。
- 每篇材料必须包含组内全部目标词，并记录每个词的实际出现次数。

## 跨账号内容复用

AI 生成的阅读材料和题目存入全局 `StudyContentCache`，不属于某个用户。缓存签名由学习模式、目标词 ID、词面、词性和释义共同计算；释义变化后会自然生成新的缓存版本。

生成计划时按组查询缓存：

1. 优先选择当前用户从未回答过的同签名缓存；
2. 其他用户是否做过不影响复用；
3. 找到缓存时直接绑定计划项并增加命中次数；
4. 只有缺少可用缓存的分组才请求 AI；
5. 同一计划可以同时包含缓存分组和新生成分组。

个人计划和答题记录只保存“使用了哪条缓存”和作答结果。清理个人学习记录会删除这些使用记录，但不会删除 `StudyContentCache`，因此其他账号和重置后的账号仍可复用已有内容。

## 内容契约

每组生成：

- 英文短标题；
- 2–4 个英文句子；
- 与英文一一对应的完整中文翻译；
- “简化全文”用的中英混合句：目标单词保留英文，其余翻译成自然中文；
- 每个目标单词恰好一道练习题，包括题型、选项、正确答案与解析。

阅读材料默认不超过 90 个英文单词；独立单词材料尽量不超过 55 个英文单词。

## 五种题型

- 单词助记：多选构词、派生词或可靠联想，不允许编造词源。
- 词义识别：在当前语境中选择准确中文义项。
- 单词匹配：同一目标词的四组英文搭配与中文释义一一匹配。
- 同义替换：选择在当前句中可直接替换目标词的表达。
- 阅读理解：依据本组短文考查词义、细节或推断，不考文章外知识。

题型详细规则见 [单词练习题型.md](./单词练习题型.md)。

## 记录与统计

提交每组时，Web 只发送单词、所选答案与作答耗时。API 使用计划中持久化的正确答案判分，再记录题型、所选答案与正误，客户端不能自行声明答对。API 同时更新累计正确率、复习次数、陌生程度和下次复习时间。整份计划全部完成后才进入结算页；中间组提交成功后直接进入下一组。
