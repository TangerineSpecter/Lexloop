# AI 学习计划生成

## 生成流程

1. 用户在“阅读材料模型”中明确选择管理员已启用的模型。
2. 首页展示到期复习总量，用户可选择本次复习数。每份计划最多选取 40 个最早到期词；未选词保持原排期，可放入后续计划。`POST /study/plans` 原子性选取本次复习词与当前新词，返回 `GENERATING` 计划。
3. Web 立即打开预习层并展示“学习计划生成中”，开始挑战按钮保持禁用。
4. Web 调用 `POST /study/plans/:id/generate`。API 先原子性领取生成任务；同一计划的其他并发请求只读取状态，不会重复调用模型。
5. API 使用用户所选模型生成结构化 JSON，校验分组、目标词、逐句翻译与逐词题目。只有校验和持久化全部成功后，新词才进入学习进度。
6. 校验成功后计划进入 `ACTIVE`；失败进入 `FAILED` 并保存错误摘要，用户可在预习层或学习历史中重试。生成锁超过 10 分钟可被重新领取，避免进程异常后永久卡住。

应试语境（`exam`）会调用 AI，但只生成原创短文和题目，并按熟词僻义、搭配、同义替换和阅读理解的配比指定题型。它不读取真题原卷。

## 分组规则

- 独立单词：一个单词一组；10 个词对应 10 篇短材料。
- 分组学习：先随机打乱，再按 2–5 个词分组，避免末尾只剩 1 个词。
- 每篇材料必须包含组内全部目标词，并记录每个词的实际出现次数。
- 若目标词条有已知 CEFR 标记，生成提示会将它作为该词条的难度线索；同组级别不同时，用更常见的周边词汇和清晰句式托住较难目标词。这不代表学习者本人的 CEFR 水平。未标记级别时不补猜，使用常见词汇和清晰句式。

复习数量是本次计划的选择，不会提前写入答题记录或修改复习排期。用户完成并提交题目后，只有本次计划内的词才更新作答与复习状态。

同一用户已有生成中、已生成未完成的正常计划，或今天生成失败但仍有计划词时，创建请求会复用原计划。首页此时显示该计划已有的复习词和新词数量，并提供打开入口；数量选择只在没有可复用计划时显示，不会让用户误以为旧计划已按新数量重排。

## 跨账号内容复用

AI 生成的阅读材料和题目存入全局 `StudyContentCache`，不属于某个用户。缓存签名由学习模式、目标词 ID、词面、词性和释义共同计算；有已知词条 CEFR 标记时也纳入签名，避免不同难度提示复用同一组材料。释义或已知级别变化后会自然生成新的缓存版本。级别未知的词继续使用旧签名，以兼容已有缓存。

生成计划时按组查询缓存：

1. 优先选择当前用户从未回答过的同签名缓存；
2. 其他用户是否做过不影响复用；
3. 找到缓存时直接绑定计划项并增加命中次数；
4. 只有缺少可用缓存的分组才请求 AI；
5. 同一计划可以同时包含缓存分组和新生成分组。

个人计划和答题记录只保存“使用了哪条缓存”和作答结果。清理个人学习记录会删除这些使用记录，但不会删除 `StudyContentCache`，因此其他账号和重置后的账号仍可复用已有内容。

## 内容契约

每组生成：

- 英文短标题；
- 2–4 个英文句子；
- 与英文一一对应的完整中文翻译；
- “简化全文”用的中英混合句：目标单词保留英文，其余翻译成自然中文；
- 每个目标单词恰好一道练习题，包括题型、选项、正确答案与解析。

阅读材料默认不超过 90 个英文单词；独立单词材料尽量不超过 55 个英文单词。

## 五种题型

- 单词助记：多选构词、派生词或可靠联想，不允许编造词源。
- 词义识别：在当前语境中选择准确中文义项。
- 单词匹配：同一目标词的四组英文搭配与中文释义一一匹配。
- 同义替换：选择在当前句中可直接替换目标词的表达。
- 阅读理解：依据本组短文考查词义、细节或推断，不考文章外知识。

题型详细规则见 [单词练习题型.md](./单词练习题型.md)。

## 记录与统计

作答前的计划响应不包含未完成组的正确答案、解析和配对关系；单词匹配题会保留短语与释义选项，但打乱两者的对应关系。已完成组（包括历史计划）仍返回完整答案，便于复盘。

学习者先完成组内所有题目，再提交整组。提交成功后，Web 才展示正确答案和解析，并提供明确的“继续下一组”入口；请求失败时保留当前选择，不揭晓答案或推进计划。Web 只发送单词、所选答案与作答耗时。API 使用计划中持久化的正确答案判分，再记录题型、所选答案与正误，客户端不能自行声明答对。API 同时更新累计正确率、复习次数、陌生程度和下次复习时间。整份计划全部完成并查看本组反馈后才进入结算页。

学习历史支持按需回看已完成计划的逐题结果。用户展开历史记录并选择“查看我的答案与解析”后，Web 读取该账号的单份已完成计划，显示保存的选择、正确答案与解析。计划列表和未完成计划不返回已选答案；未提交的分组继续隐藏正确答案。回看是只读操作，不创建新的作答记录或更新复习排期；旧记录没有保存具体选项时，只展示能够确认的历史信息。
