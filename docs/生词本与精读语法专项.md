# 生词本与精读语法专项

## 入口与收藏

首页新增生词本、短文精读和语法专项入口；侧栏可直接进入。统一页面为 `/dashboard/notebook`，`tab=words`、`sentences`、`reading`、`grammar` 分别定位四个栏目。首页入口不预取数据，不启动生成或轮询。

个人生词本复用既有个人词书、词条和复习进度，原旅行生词本自动显示在这里，旧接口及 URL 保持兼容。分组阅读、精读短文、每日一句详情和微故事解析页提供词汇收藏表单；旅行场景继续使用原收藏操作。微故事的重点表达只在用户先提交理解并揭晓解析后提供。支持英文单词和短语、中文语境义、原句与来源；也可手动录入。个人规范键包含账号 ID，不修改系统词条和他人的词汇。旅行页只加载旅行来源的分页摘要，并链接完整生词本；个人词汇在复习与学习计划中优先展示保存的语境义。练习答案提交后，反馈和历史逐题回顾会带回该词条保存的来源场景与原句；提交前不返回这份原句，旧记录没有来源句时保持原有反馈。

可在「批量导入自己的词表」中粘贴两列或三列 TSV：英文表达、中文释义、可选例句；预览通过后一次最多加入 40 行。导入使用当前账号的个人词书，同账号按大小写与空格规范化去重；重复收藏不覆盖已有释义、原句或复习进度，已移除词条会恢复原状态。新词加入现有动态复习；没有例句时保持为空，不会生成或编造语境。整批在一个数据库事务中提交，任何失败都不会只留下部分词条。粘贴内容只保存在当前页面内存中，失败时可重试；刷新或离开页面会清空未提交内容，不跨设备同步。导入不上传文件、不调用 AI，也不新增数据库表。

新收藏立即加入动态复习。同一账号按规范化英文拼写去重；并发收藏使用数据库事务锁，按最大序号分配新位置，移除中间收藏后也不会撞号。重复收藏保留首次词义、原句、来源及已有学习状态，不会把已掌握词自动改回复习。用户可主动加入今日复习、标记掌握或逐项移除收藏。移除收藏仅隐藏收藏，不删除词条、复习进度、错题或历史计划；重新收藏可继续原来的学习状态。完整清空个人词书与清理全部学习记录仍遵循原来的明确清理操作。

生词列表支持搜索、来源筛选和每页 20 条分页。最多跨页勾选 6 个词，选择保存在当前 URL 中；清空勾选不删除收藏。「句子收藏」复用每日一句已有的收藏、详情、取消收藏和分页 API；整句收藏与词汇收藏分别保留自己的学习内容。

个人生词本还提供可选「练习回想」模式：先看英文词和原句，在心里回想中文释义，再逐项揭晓。普通浏览仍直接显示释义；模式和揭晓状态只保存在当前页面，切换搜索、来源或页码会重新遮住答案，切换账号会重置整个页面状态。这里不输入答案、不判分、不产生答题或掌握记录，也不额外请求 API；回想只是学习者自选的提取练习，不会调整间隔复习。

生词本可对当前页有中文释义的词做可选「听音拼写」：练习时暂时隐藏词卡和其他编辑区，先听浏览器提供的英语发音并输入拼写，再对照答案；结束后恢复练习前的列表与编辑内容。大小写和多余空格不计差异，标点仍需匹配。答错后会定位错字、漏字或多字，并以文字说明应改的字符；超长输入跳过逐字符定位，但仍展示标准拼写和发音入口。用户可随时显示答案或结束；没有英语语音时不会把人困在题目里。练习仅在当前页面内运行，不发送作答或发音文本到 Lexloop API，不保存成绩、学习事件或复习状态。语音由设备/浏览器提供，不保证离线；切换词、结束或离开页面会停止旧语音。

同一练习区还提供可选「按原句补词」：只从当前页有中文释义、且已保存原句包含完整目标词或短语的收藏中抽题；句中重复出现的目标表达会全部挖空，避免剩余文本直接泄漏答案。提交或主动揭晓后显示原句与目标表达。它只对照拼写，不判断整句是否自然或用法正确；和听音拼写一样，只在当前页面运行，不发送答案、不保存成绩或复习状态。没有合适原句时该入口禁用，听音拼写仍可使用。

## 生词短文精读

选择 1–6 个个人收藏词后进入精读，选择 A2/B1/B2 材料难度并生成。难度仅控制材料，不代表用户测评等级。后台使用用户已选择且启用的阅读模型生成短文、逐句译文、结构或搭配讲解，以及 3–6 道读后选择题。服务端验证篇幅、目标词完整边界、句子数量、选项和答案格式，不合格内容重试后仍失败则显示错误。

切换阅读历史或来源原句时，词汇收藏表单会重建，避免沿用上一篇的原句与草稿。短文按句展示，目标词高亮；译文与讲解可按需展开，各句可继续收藏单词或短语。阅读小测交卷前 API 不返回答案索引和题目解析。交卷后由服务端判分并保存答案、分数、交卷时间与解析。每份练习只有一次成绩，同答案重放幂等，变更答案返回冲突；需要重练可生成新短文。读后成绩只记录阅读表现，不推测逐词掌握。

## 语法薄弱项专项

收集最近 30 天内的三种线索：每日输出的批改与改写、旅行场景明确标记为 grammar 的纠错、语法专项中答错的题目。候选扫描有上限：最近 15 份输出日期、每份最多 3 次完成批改；最近 15 个场景、每个最多 10 个回合；最近 10 份已交卷语法专项。合并按时间取最近 20 条。输出语法分数仅筛选候选批改，不直接认定某类错误。

模型根据线索整理时态、冠词、介词、主谓一致、句子结构、可数性等类别，附中文讲解、迁移例句与变式选择题。每个类别的原始依据 ID 必须存在于当前账号保存的输入快照中；页面展示原文、参考改写和教师反馈。线索数量不是错误次数，也不表示能力等级；证据不足的类别标为「基础补充」。AI 分类仍属于练习建议，不能替代完整语法诊断。

没有线索时提供确定性的六题基础自测，不依赖模型；其错题会成为后续专项的学习证据。已有线索的分析与变式生成需要选择可用模型。交卷规则与阅读小测相同，可从历史继续或回顾。未交卷的选项按账号和本份练习保存在当前设备，刷新或重进时可恢复；用户可主动清除，题目内容变化时旧草稿失效。此草稿不上传、不计成绩，也不会改动学习证据；交卷成功后按本次提交快照清理。浏览器本机存储不可用时仍可完成练习，但刷新可能无法恢复选择。

## 后台、权限与数据流

- `learning-lab` 是独立 Nest 业务模块；Web 仅通过 API 客户端访问。`LabLesson` 保存用户、内容类型、请求幂等编号、输入快照、生成内容、作答与状态。
- API 创建任务后进入 BullMQ `learning-lab` 队列；现有 headless Nest Worker 运行生成，不新增 HTTP 服务。队列仅携带记录 ID 与随机 capability，不包含原文、模型密钥或 JWT。
- capability 15 分钟有效，仅存哈希；两分钟数据库租约防止恢复任务重复处理。Worker 调用模型限时 90 秒，并发 2，全队列每分钟最多 6 次任务，失败最多 3 次指数退避重试。失效租约、已删除记录与重复任务不能重新写入结果。
- 同账号最多一个生成中的任务；24 小时最多创建 20 份内容，失败也计入防滥用上限。队列写入最多等待 5 秒；历史、详情会将超过 15 分钟的任务标记失败。所有公开查询、选词与交卷均以当前账号隔离。
- 前端只在当前页面可见且当前记录生成中时查询，每 3 秒一次、每轮最多 40 次；随后手动继续查看。离页停止查询，后台继续；历史每页最多 10 份。未交卷历史同样不返回答案。
- 完成交卷分别写入 `READING_COMPLETED` / `GRAMMAR_COMPLETED` 学习事件，纳入阶段统计、连续打卡和每周处方的活跃日，不伪造词汇答题或语法掌握证据。
- 「清理全部学习记录」同时删除精读与语法专项，包括生成中的记录。清理与创建使用同一用户事务锁；清理递增账号的学习记录版本，创建请求在读取快照前记录版本，并在持锁后验证，清理前已开始的请求会被拒绝，不能重新保存或入队旧原文。旧任务不能凭 capability 写回。只清空个人生词本不删除已经保存的练习快照。

## 验证

API 单元测试覆盖材料与答案校验、短语边界、证据 ID、公开答案过滤、服务端判分、账号隔离、任务 capability 和租约。数据库集成测试使用隔离 PostgreSQL，验证并发收藏、原句及掌握状态保留、删除后序号、任务幂等、交卷幂等、错题证据、清理后回写拒绝，以及精读/语法创建与清理并发时的旧快照拒绝。

已验证的完整 API 入口是 `node scripts/test-api-isolated.mjs`：它会启动隔离 PostgreSQL/Redis，设置 `LAB_TEST_DATABASE_URL` 并执行包含本文件集成用例的完整 API 套件；若仍有跳过项会失败退出。生成链路使用测试 Provider stub，不会调用外部模型，也不连接默认开发或生产数据库。`pnpm test:api:full` 是同一脚本的包管理器别名，但 pnpm 会先执行自己的版本与依赖状态检查；只有 pnpm 版本和仓库 `packageManager`、已安装依赖匹配时，别名才会到达测试脚本。别名本身不属于隔离 API 验收结果。

浏览器回归测试使用运行中的 Web 构建和独立 Chromium，API 全部为本地页面内模拟，不连接真实账号与数据库。在 `apps/web` 目录设置 `LAB_BROWSER_TEST_URL=http://127.0.0.1:52100` 后，已验证的测试入口是 `node --test --test-concurrency=1 test/*.browser.test.mjs`；除切换历史后原句和草稿重置、保存的原句与来源一致外，也覆盖精读/语法小测选择在刷新后的恢复、账号切换隔离、清除、提交失败保留和成功提交后按快照清理，并确认作答草稿不产生 API 请求。可用 `LAB_BROWSER_EXECUTABLE` 指定 Chromium 路径。`pnpm --filter @lexloop/web test:browser` 是同一 Node 脚本的包管理器别名，但会先执行 pnpm 自身的版本与依赖状态检查；该检查不属于浏览器验收。未设置 URL 时测试跳过。
