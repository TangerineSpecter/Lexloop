# 学习专项与每周处方

首页的学习专项入口放在「今日学习词汇」后面，默认收起。侧栏「学习专项与处方」进入 `/dashboard/practice`。`tab=output`、`confusion`、`weekly` 可直接访问对应栏目。首页入口不预取练习页、不拉取专项数据。

## 每日输出挑战

- 按 `APP_TIMEZONE`（默认 Asia/Shanghai）每天保存一份挑战，最多三个不重复目标词或短语；优先选当前待巩固词，再选近期学习词，数量不足时从默认词书补充。短语限制为最多四个英文词、48 个字符且不含句子标点，较长原句不会作为写作目标。没有可用词汇时引导先选词书。
- 写一小段英文，使用全部给定词或短语的完整拼写；短语匹配不区分大小写，允许词间空格或换行变化，但不会因更长单词中的子串而算匹配。建议 20–80 词，输入最多 1800 字符，提交前需选择已启用模型。缺少模型时，可从当前练习直接打开阅读材料模型设置；打开、加载失败或没有可用模型都不会清除本机原文和请求编号，也不会创建批改提交或学习记录。选择模型后返回同一练习可继续提交；模型列表请求仅在用户打开设置时发起，不调用模型生成。
- 每天最多三次有效提交，失败不占这三次额度；为限制异常重试，每天最多十份提交。同一客户端请求编号只产生一次提交，同一用户不能同时提交多份批改。未完成或响应状态不明时，本机草稿会连同账号、挑战、日期、原文和请求编号一起保存；刷新后相同原文沿用同一编号。完成后只保留原文草稿，修改原文会生成新编号。草稿仅在当前设备，不跨设备同步；本机存储不可用时会提示刷新可能丢失。
- AI 按词义与搭配、语法和连贯性给出反馈、简短建议与参考改写；使用情况还会由服务器检查完整词边界，避免把 `effective` 算作使用了 `effect`。总分按逐词正确率 60%、语法 25%、连贯 15% 计算，不表示 CEFR 等级。
- 可回到原文重写；查看反馈时并列展示原表达和参考表达，并保留题目与目标词作为对照上下文；逐词反馈标出原回答中首个完整拼写片段。未找到时只说明拼写未完全匹配，词形变化或标点写法可能未被覆盖；片段定位不代表用法正确或已经掌握。今天的记录可展开查看，过去记录点击后按学习日期分页，每页最多十条；利用用户与日期索引，不扫描并加载全部历史答案。展开历史记录后可先临时试写再查看原回答与反馈，也可直接查看；试写只保留在当前页面，不保存、批改或计入练习。每日挑战草稿按账号在本机只保留一份，不自动上传。

## 易混词对比训练

- 首版提供十组常见易混词，每组四道交替语境填空，覆盖 affect/effect、borrow/lend、rise/raise 等。学习者可先答题，或按需展开对比规则和例句。
- 推荐优先级：包含待巩固词、关联近期学习词、常见词组；同优先级优先未练习组。推荐只使用当前账号记录。
- 「已练习」按固定词组通过用户、词组与日期组合索引各查询最近一条，不聚合全部历史作答。
- 服务端校验题目集合和选项并判分，交卷后提供逐题解析。重复请求不重复写入训练或学习事件。24 小时最多三十组。
- 最近二十条训练保存在栏目中，界面默认展示最近十条。仅已经关联到个人学习进度的词会写入词汇答题与复习链路；未学过的对比词不会自动加入当前词书。
- 同一词在一组的全部对应题目都答对，才算本组该词正确；每组每词最多一份掌握证据，不能在一组内直接累计两次纠正。

## 每周学习处方

- 展示当前自然周，证据取最近七个本地日历日（含今天），并结合当前到期复习和活跃薄弱项。页面按需读取，完成练习后可手动刷新，无后台定时生成或额外模型调用。
- 三项任务分别指向主动输出、易混词辨析，以及到期复习/待巩固/基础学习。原因明确引用数量；证据不足时给基础任务，不推测强弱或能力等级。
- 单词作答与专项事件、正式测评和旅行场景共同形成活跃日期。词汇正确率包含输出和对比中关联到已有词汇的逐词结果，不等同于原始填空题正确率。

## 错题、统计和清理

输出与对比中的词汇证据分别使用 `OUTPUT` 和 `CONFUSION` 类型；错误激活待巩固，连续两次成功证据纠正，与既有动态复习算法共用。已手动标记掌握的词不会被专项自动改写掌握状态。

错题详情保留原文/题干、作答与反馈。对新题型点击生成专项会进入对应练习栏目，避免送入只支持客观题的原生成器。专项完成会点亮学习统计打卡；输出历史与对比记录在专项栏目查看。

错题页的选择若混有普通题型、每日输出或易混词，会先按题型展示可走的练习路径。普通专项只接收兼容的普通题型词；每日输出和易混词继续使用各自的当日目标与推荐规则，并明确说明所选词没有被直接带入专项。

首页连续学习卡片读取 `/reports/streak`，与学习统计的连续天数共用已完成单词练习、场景、正式测评和专项事件作为学习日证据。连续天数按浏览器所在时区的本地日历日计算；没有今天的完成记录时，仍显示截至昨天的连续天数，并明确提示今天还没有完成活动。重复完成事件只算一个学习日；打开首页或进入练习不会自动计入。加载失败时显示不可用状态，不伪装成零天。

阶段复盘的近 7 天、近 30 天和近 1 年也按请求中的浏览器时区边界统计；日期标签与单词答题、场景、测评和专项活动归日使用同一时区，并按本地日历日处理夏令时变化。未传时区的 API 调用继续使用 UTC。

「清理全部学习记录」同时删除输出挑战及提交、对比训练、相关答题和事件，本机输出草稿也会清除；不会删除系统词表和公共生成缓存。已清理的任务无法凭旧 capability 写回证据。

## 异步与性能边界

- API 快速创建提交并入队，不等待模型；入队等待最多五秒。队列只含提交 ID 和随机任务凭证，不存放答案、模型密钥或用户 JWT。
- Worker 并发二、全队列每分钟最多六个任务，每任务最多三次指数退避重试。模型调用最多九十秒；处理租约两分钟，任务凭证十五分钟过期。原始 Provider 错误体不写入日志或队列失败原因。
- Worker 中断后恢复的任务若仍被旧租约占用，会延后到租约到期再处理，不消耗模型失败重试次数，也不重复写入学习证据。
- 同一提交编号与答案再次到达时，15 分钟有效期内的失败输出记录会在数据库内原子领取重试，轮换仅存哈希的 Worker capability，并使用新 BullMQ job ID；并发重放只会入队一次。原答案和答题时间保留，批改成功前不会新增学习证据；再次入队失败仍保持失败且不占用有效批改次数。凭证过期后不再重用旧任务，页面保留原文并明确提示下一次主动提交会创建新任务。
- 批改复用现有 headless Nest Worker，与每日一句共享服务端 Prisma 和加密模型适配器，不新增 HTTP 服务或暴露模型上下文接口。任务 capability 只在内部服务方法间使用，数据库仅存哈希；失效租约不能写入。Web 只可读取已过滤的作答状态与结果。
- 前端只在存在待批改任务且页面可见时查询，三秒一次、最多四十次；之后由用户手动继续查看。离开页面即清除查询，不增加首页后台轮询。
- 词汇候选集、训练列表和历史页均有上限；周处方使用数据库计数和日期聚合，不下载全部历史答案。WordReviewAttempt 新增用户和时间组合索引。无无限滚动或按累计历史增长的页面列表。

验证覆盖日期/周边界、AI 结构与目标词校验、任务权限/租约、幂等与对比判分；联调应使用隔离 PostgreSQL/Redis 与本地 Provider stub，不以外部模型输出稳定性作为自动化测试前提。

已验证的完整 API 入口是 `node scripts/test-api-isolated.mjs`：它会启动一次性、仅绑定 loopback 的 PostgreSQL 与 Redis 容器，先按当前 schema 生成 Prisma Client，再应用迁移并执行完整 API 测试套件。入口会把 `DATABASE_URL`、`LAB_TEST_DATABASE_URL`、`PRACTICE_TEST_DATABASE_URL` 指向同一个空测试库，并设置 `PRACTICE_TEST_REDIS_URL`；Vitest 若有任何跳过项，入口会以失败退出。它只删除本次创建的容器，不连接已有开发或生产数据库，也不使用外部模型。该入口需要可用的 Docker Engine 和 `pgvector/pgvector:pg16`、`redis:7-alpine` 镜像。`pnpm test:api:full` 是同一脚本的包管理器别名，但 pnpm 会先执行自己的版本与依赖状态检查；只有 pnpm 版本和仓库 `packageManager`、已安装依赖匹配时，别名才会到达测试脚本。别名本身不属于隔离 API 验收结果。
