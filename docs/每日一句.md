# 每日一句

首页「每日一句」直接显示英文短句、语法重点、生成日期和已读状态。打开详情后查看中文翻译、彩色结构拆解、用法问答、可套用句型和迁移例句，并可收藏和反馈难度。主语、谓语、状语表示句子成分，NP、PP 等短语类型单独标注，避免混淆两个层次。

## 生成与未读规则

管理员可在「系统设置 → 功能开关 → 每日一句」设置全局开关，默认开启，设置持久化到 `SystemFeatureSetting`。关闭后首页隐藏入口，定时扫描不再入队，已排队但尚未开始的生成与手动重试也在服务端跳过；已经开始的生成可能完成。历史句子、收藏与难度反馈保留，重新开启后仍复用已有未读句子，不批量补发。已打开的首页会在下一次状态刷新时更新（可见页面最多约一分钟），刷新页面可立即获取状态。

- 默认每日北京时间（Asia/Shanghai）06:00 开始为已选择可用 AI 模型的用户提前准备内容。首页访问、详情访问、回顾和收藏均不启动生成。
- 后台独立 Worker 每五分钟检查一次，并在启动时检查，以恢复停机期间错过的当天生成。实际生成可能受排队、模型速度和服务可用性影响。
- 每个用户最多保留一条未读内容。存在未读内容时保留原句，不覆盖、不继续生成；首页展示和浏览回顾列表不算已读。
- 详情成功加载并展示后，客户端单独提交已读；已读时间只写一次，重复打开不会重置。
- 若句子在当天 06:00 或之后才被首次阅读，当天不补发，下一日的定时检查才会准备新句子。读完当天句子也不会立即生成第二句。
- 每个用户、每个北京时间日期最多成功生成一条。断开几天后不补发错过日期；旧队列任务跨天后直接跳过。
- 未选择模型或所选模型已停用时不调用 Provider。首页说明需要先在阅读材料模型设置中选择模型；选择后由后台下一次定时检查准备，06:00 前等待当天定时检查。
- 自动任务最多尝试两次；失败后可手动重试，数据库把当天总调用尝试限制为三次。没有成功内容时提示等待或失败；已有内容则继续展示，失败不会破坏历史和收藏。

## 教学与个性化

使用当前用户选择的模型，服务端解密配置，浏览器不持有密钥。生成输入包含最近 25 个学习词、最近 5 个活跃薄弱项、可信且非临时的场景测评等级、最近 10 条句子的重点，以及用户最近一次明确的难度反馈。难度反馈按最后选择时间读取，不受句子日期或回顾列表分页影响；最近 10 条句子只用于避免重复和连续讲同一重点。缺少可信等级时从 A1 开始；旅行测评仅作辅助证据，不等同于全面语法测评。

每句优先 5–16 个词、一个核心用法、尽量 0–2 个生词，解释“为什么这样写”“什么情况下能用”和适用限制。反馈“有点难”时要求后续降难度；“太简单”时小幅增加；“刚刚好”时保持。难度和生词数是模型生成约束，首版不能保证精确测量用户全部已知词汇或自动判定语法解析绝对正确。

内容落库前检查结构、中文教学字段、句长、短语片段是否能按原顺序还原全部原句（包括标点）及近期原句去重。不完整或错位内容不会展示。查看、收藏和难度反馈不改变单词掌握度，也不自动算完成学习任务。

## 数据流与并发

Web → JWT API → Prisma 读取当前内容、分页历史及保存交互。只有显式失败重试接口向 BullMQ 入队，API 不等待 AI。后台调度和 AI 生成在 `apps/worker` 进程组中执行。

Worker 启动一个复用 API 服务实现的无 HTTP Nest 上下文（`apps/api/src/daily-sentence-worker.ts`），只加载 Prisma、配置与模型适配器，不启动 API 控制器或词表种子。Worker 生产镜像携带该入口的编译产物及依赖，并取得数据库、Redis 和 `AI_CONFIG_ENCRYPTION_KEY`。

`DailySentence` 保存生成日期、内容快照、状态、尝试次数、生成令牌、已读、收藏、难度反馈和难度反馈更新时间。升级时用原记录的更新时间回填已有难度反馈。预留生成名额时锁定用户行，短事务中检查未读、时间边界和当天次数，AI 调用在事务外执行；每次请求超时 120 秒。十分钟以上的中断预留可在后续检查中恢复，最多三次。完成时校验令牌，阻止旧任务覆盖新尝试。数据库另有用户/日期唯一索引及“一用户最多一条未读 READY 内容”的部分唯一索引。每次模型调用记录 AI 审计，错误只保存安全提示。

历史按日期倒序每页 20 条，支持只看收藏；请求与读写均按当前用户隔离。收藏只引用同一内容快照，取消收藏不删除历史，更换模型不改写已有解析。
