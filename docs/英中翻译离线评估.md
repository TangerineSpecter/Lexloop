# 英中翻译离线评估

这套评估材料用于整理精读逐句翻译的原意边界，覆盖否定、时态与先后、施事、数量、因果关系和条件句。它不是经独立审校的语料，也不是模型生成结果或真实模型质量报告。案例由仓库作者编写；文中的参考译文、近义表达和偏义反例是评估提示，尚未经过独立语言审校。

## 运行

从仓库根目录执行：

```sh
node apps/api/scripts/evaluate-study-translations.mjs
(cd apps/api && ./node_modules/.bin/vitest run test/study-translation-evaluation.spec.ts)
```

第一条命令校验案例结构并输出 JSON 报告。没有候选生成结果时状态为 `NOT_EVALUATED`，不会报告通过。脚本不访问网络、不调用模型，也不依据关键词或与参考译文的字面相似度判断语义。

## 提交候选结果供人工复核

生成一个未评审模板：

```sh
node apps/api/scripts/evaluate-study-translations.mjs --template /tmp/study-translation-review.json
```

把实际候选译文放入 `outputs`，填写其 `caseId` 和来源说明；在理解上下文后，由复核者将 `review` 标记为 `meaning_preserved`、`meaning_changed`、`uncertain` 或保持 `not_reviewed`，并可在 `reviewerNote` 记录理由。随后运行：

```sh
node apps/api/scripts/evaluate-study-translations.mjs --outputs /tmp/study-translation-review.json
```

输出中的标注只按原样汇总，不会被工具独立验证；尚有未标注候选时会报告部分标注。不同于参考译文的表达不会自动判错，同义表达需要按完整语境复核。请勿将虚构测试数据描述为模型输出，不要把访问令牌或个人数据放入评估文件。

该工具提供可重复的案例结构与标注汇总，不提供通用语义判分器。当前案例不能证明真实生成器的准确率；真实模型质量仍未评估。要开展模型评估，需另行取得真实生成输出并进行有依据的语言复核，本工具本身不会发起模型请求。
