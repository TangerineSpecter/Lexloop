# 日常词书词边界调查与修订

## 已确认的原因

“1,096 行被排除”指只读候选盘点脚本的单词筛选：正则只接受单个英文词面，带空格的行被留作词边界核对。它不是 XLSX 解析报错，也不代表 1,096 行全部错误；其中 `human body`、`skin cell` 等可以是正常短语。

检查仓库最早包含该词书的提交 `33a40ee378594f3cad2d42516358eb6db201d61d`、导入功能提交 `4418246353438047973d5dd322b060bcf236e08c` 和当前文件：三个版本均有 1,177 行，全部词面及顺序一致，合并单元格数量都是 0。最早文件的 XML 已直接包含：

```xml
<c r="A7" t="inlineStr"><is><t>born birth age sex</t></is></c>
```

因此至少这些词列在进入当前导入器前已经写成一个字符串单元格。导入器按“一个单元格是一条词条”原样读取，清洗脚本按完整词面查词，不会把其中的单词分别匹配；这能解释整串缺释义，但不能据此还原所有行的边界。最早源文件全部 1,177 条释义都为 `无`；后续清洗只补了 62 条，现在逐项补充后有 68 条。未找到生成最早词书之前的原始材料，无法确定最初是人工排版还是上游抽取造成。

可重复检查：

```sh
git show '33a40ee:apps/api/assets/vocabulary/通用/日常生活单词.xlsx' > /tmp/daily-original.xlsx
node scripts/vocabulary-coverage-inventory.mjs
```

最早源文件 SHA-256：`d6618c6cda3f8dd6d004e84fe726b762764cbbd45d4f00c4d18e6a1d71f19ebb`。导入时代文件与已有候选归档一致：`86da0383a0e8953c0cd28b2ce2b462d9b1ed5beb8428dc68fcd5b7f06417b5bb`。本轮没有改写 XLSX 或历史来源批次。

## 有界的实际修复

新增显式边界 manifest：`apps/api/src/modules/vocabulary/daily-vocabulary-boundaries.json`。核验为助手逐项核对词面和邻近主题，不冒称人工专业审校。

| 源 Excel 行 | 原词列                           | 修复为独立词条                       |
| ----------- | -------------------------------- | ------------------------------------ |
| 7           | born birth age sex               | born / birth / age / sex             |
| 8           | male female gender               | male / female / gender               |
| 12          | nationality citizenship language | nationality / citizenship / language |
| 18          | lung liver appendix              | lung / liver / appendix              |
| 24          | eyelid eyebrow lip tongue        | eyelid / eyebrow / lip / tongue      |

只针对这五个已经逐项核对的词列，不按空格批量拆分。严格匹配源路径、全部词面顺序的 SHA-256、原行号和完整词面，并要求释义和英美音全部缺失；任一不匹配则跳过该书，保留既有数据，其他词书继续导入。`human body`、`skin cell`、有歧义的 `letter call sign` 和可疑的 `brain console` 都保持原样。

五行展开为 **17 个词条**，新词书逻辑记录数从 **1,177 → 1,189**。新增词条只携带缺失值，没有生成或移用释义/IPA；在完整安装中，已有全局同名词条仍按原导入规则复用，这不是本轮新增的词典内容或语义质量验证。原始词表的完整来源授权链仍未核实；本轮只重新组织仓库已有词面，没有引入外部词典、模型内容或新的词义许可声明。

## 已有安装保护

新增可空 `VocabularyBook.sourceRevision`。迁移只添加列，既有词书保持 NULL，不更新任何词条、关联或学习进度。

当前修订为 `daily-boundaries-2026-11-03-v1`。导入前仅尝试用 `createMany(skipDuplicates)` 预留新词书，再读取实际修订号、SYSTEM 类型及无所有者条件。旧词书 NULL、其他修订或个人书均跳过整个日常词书导入，输出明确维护日志；不改旧 sourceRevision，也不重排 position。预留后中断可由相同修订的下一次启动继续完成；并发初始化使用相同稳定位置与已有唯一约束去重。

所以：**新装/尚不存在该书的安装采用修复；已有旧书不会自动修复，实际迁移数为 0。** 不应通过手工改 revision 或删除旧词书来绕过保护。旧书的五到十七映射涉及 position、复习关联和历史引用，需另行设计审阅及迁移流程。此前 v1.27.153 的 6 词 / 12 字段回填仍可独立预览，它不会处理词边界或关联重排。

## 覆盖与限制

- 原始文件：1,177 行，缺释义 1,109，英美音各缺 1,117；本轮这些源字段数量不变。
- 单词候选筛选：13 个独立词面候选、1,096 个含空格的待核对行。仅确认并修复其中 5 行，剩余 **1,091 行未分类**，不能把它们全称为坏数据。
- 新导入结构：1,189 记录，其中上述 17 词在单书隔离测试中均没有释义或 IPA；不把拆分数量算作内容补齐数量。
- 已有数据库：不进行自动拆词/回填；个人数据、学习进度和原有位置保留。未操作生产、付费模型或外部词典服务。
