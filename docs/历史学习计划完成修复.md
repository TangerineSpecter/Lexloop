# 历史学习计划完成修复

v1.27.170 已修复并发最后两组提交时遗漏计划收尾的问题。本工具只处理升级前可能留下的历史状态，不随升级、登录或计划读取自动执行。未检查或操作生产，不能推断生产存在多少此类记录。

卡住的计划可能已经有全部题目完成时间与作答/SRS记录，却仍为 ACTIVE：完成历史不包含它，继续学习会反复返回原计划，渐进路径可能缺少完成后解锁。仅凭“所有现存题目已完成”不足以自动修复，因为删词导致的级联删除、重复作答或缺失材料也可能造成相同表象。

## 判定范围

只允许 ACTIVE 且完成字段为空、至少两组材料与现存题目集合一一对应的计划。每题须有一条归属当前用户和词条的普通作答、有效问题快照、题型一致、选择值属于原选项或合法匹配集合，并有对应的个人作答次数记录。时间不能位于未来，题目完成顺序须与生成/开始时间一致；每组的完成时间一致。作答数据库默认时间可能是事务开始时间，因此不强制其晚于应用产生的题目完成时间。

以下不会自动修复：部分完成、空计划、删掉部分题目但原材料仍引用它、缺失/重复/混杂作答、无法验证选项或个人进度、替代计划链、异常时间。普通 NORMAL 计划和当前 v1 渐进计划可核验；其他用途或旧版渐进路径列为人工核查。渐进路径必须存在且不低于该计划阶段；与计划阶段相同时可按既有完成解锁规则推进一阶段，已经更高则不回退。该解锁不是能力评估。

工具不重新判分，不改 `WordReviewAttempt`、`UserWordProgress`、薄弱项或复习时间。错误答案也可以构成完成证据；不据“答对”推断历史状态或学习能力。

## 显式操作流程

先应用 `20261103230000_study_completion_repair` 迁移并构建 API。该迁移只增加回执表，不更新任何历史计划。工具通过已构建 API 模块运行，必须显式指定保存数据库连接地址的环境变量；不会隐式选取 `DATABASE_URL`。

以下命令只展示隔离测试库的调用形式，不授权生产执行。`PLAN_ID` 必须替换为已选定的具体计划；不要把数据库连接地址写进命令行或回归报告。

```bash
node scripts/repair-study-completion.mjs scan --database-url-env LAB_TEST_DATABASE_URL --limit 50
node scripts/repair-study-completion.mjs preview --database-url-env LAB_TEST_DATABASE_URL --plan-id PLAN_ID --out /tmp/completion-preview.json
```

scan 只列出初筛候选 ID，每批最多100条，可用 `--after-id` 传上一批最后 ID 继续；候选不是批准修复。preview 只读，生成 `ELIGIBLE`、`NOT_APPLICABLE` 或 `MANUAL_REVIEW` 分类及原因。预览文件包括目标用户/计划、证据摘要和拟修改状态、完成时间、可能的阶段变更，不含题文或答案明文。文件权限0600，拒绝覆盖已有文件。

核对该份具体预览后，才可对同一清单执行：

```bash
node scripts/repair-study-completion.mjs apply --database-url-env LAB_TEST_DATABASE_URL --manifest /tmp/completion-preview.json --confirm REPAIR_COMPLETION_METADATA
```

apply 按用户→计划→题目→个人进度锁序，在可串行化事务中重新读取和比较完整证据摘要；预览过期、内容改动或拟修改值被篡改均拒绝。只写计划 COMPLETED 和最后一组的原完成时间，以及预览列明的阶段推进；同事务保存唯一 `StudyPlanCompletionRepair` 回执，记录前后元数据和证据摘要。回执失败会回滚整个修复。

并发修复和重复执行同一清单只生效一次。仅可串行化冲突/死锁最多重试三次整事务；连接故障或提交确认丢失不自动重试。此时不能断言“未修复”，可检查回执或显式重用同一清单确认。若当前状态与回执不同则转人工核查。工具没有批量 apply、自动回填或盲目撤销；之后的新学习行为不能靠把计划改回 ACTIVE 来“撤销”。用户删除计划或账号时回执随计划级联删除。

## 验证边界

隔离 PostgreSQL 通过实际 `StudyService.completeGroup` 产生作答、薄弱项和 SRS，再仅模拟丢失收尾元数据，检查预览零写入、普通/渐进修复、错误答案保留、并发幂等、重复执行、部分/重复/缺失/越界证据拒绝、并发编辑使预览失效和回执失败回滚。CLI 亦在隔离库验证显式参数、文件权限、不覆盖及重复 apply；没有调用模型或接触生产。不能用这些测试声称真实用户历史已修复，或模型语义正确。
