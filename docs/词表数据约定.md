# 内置词表数据约定

本文约定 Lexloop 内置词表的源文件组织、导入规则和用户端呈现方式。词表的原始 Excel 文件只用于导入；运行时词条、词书和学习进度均以数据库为准。

## 源文件目录与命名

内置词表统一存放于 `apps/api/assets/vocabulary`。顶层目录分为学习学段、考试、教材、专项和通用词表，不能把考试名称或教材名称直接作为“学段”。

学段教材使用以下层级：

```text
{学段}/{教材版本}/{年级}{册次}.xlsx
```

其他类型使用以下层级：

```text
考试/{考试系列}/{词书名}.xlsx
教材/{课程或教材系列}/{词书名}.xlsx
专项/{专项主题}/{词书名}.xlsx
通用/{词书名}.xlsx
```

当前目录示例：

```text
apps/api/assets/vocabulary/
├─ 小学/人教版/三年级上.xlsx
├─ 初中/人教版/人教版初中英语七年级上册.xlsx
├─ 高中/人教版（2019版）/人教版高中英语必修第一册.xlsx
├─ 大学/新视野大学英语读写教程（第三版）/新视野大学英语读写教程1（第三版）.xlsx
├─ 考试/大学英语四六级/四级核心单词.xlsx
├─ 教材/新概念英语/新概念英语第一册（新版）.xlsx
├─ 专项/固定搭配/高考词组.xlsx
└─ 通用/日常生活单词.xlsx
```

- 学段示例：`小学`、`初中`、`高中`、`大学`。
- 教材版本示例：`人教版`、`外研版`；同一版本有新旧课标时，在目录名中标明，例如 `人教版（2019版）`。
- 考试系列示例：`高考`、`考研`、`大学英语四六级`、`托福雅思`；它们不是学段。
- 文件名仅使用“年级 + 上/下册”，例如 `三年级上.xlsx`；不要把已在目录中表达的信息重复写入文件名。

导入程序从目录和文件名读取词书元数据，不以人工填写的展示名称作为唯一依据。文件移动或重命名后，须同步更新导入配置或重新执行导入。

## Excel 格式

每个文件只包含一册词书，首个工作表第一行必须具有以下列：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `单词` | 是 | 单词或词组；去除首尾空格后不能为空。 |
| `英音` | 是 | 没有可靠音标时填写 `无`，不得留空。 |
| `美音` | 是 | 没有可靠音标时填写 `无`，不得留空。 |
| `释义` | 是 | 原始释义；暂缺时填写 `无`，不得留空。 |

### 音标格式

- 音标是否带外围的方括号或斜杠不影响字段识别和入库，例如 `ruːˈtiːn`、`[ruːˈtiːn]` 和 `/ruːˈtiːn/` 都是可接受的源数据。
- 导入时应去除音标首尾空格，以及最外层成对的 `[]` 或 `/ /`，数据库统一保存纯 IPA，例如 `ruːˈtiːn`。
- 前端负责统一展示样式。当前产品建议使用 `/ruːˈtiːn/`，不要把展示符号固化在数据库中。
- 只有单侧符号、括号不成对或包含其他说明文字时，不自动剥离，应记录为待检查数据。

### 释义与词性格式

- 同一个词性的多个义项使用中文分号 `；` 分隔。
- 不同词性必须在同一个 Excel 单元格内换行，每行以词性缩写开头；编辑 Excel 时可使用单元格内换行。
- 不要使用分号区分词性，因为分号同时用于分隔同一词性的多个义项。
- 没有明确词性的词组可只写一行释义，不强制补造词性。

推荐格式：

```text
n. 常规，惯例；生活乏味，无聊；（演出中的）一套动作；（计算机）例行程序
adj. 常规的，例行的；平常的，毫不特别的；平淡乏味的
v. <罕> 按惯例安排
```

导入程序应保留原始释义，同时按换行解析词性，再按分号解析该词性下的多个义项。前端遍历结构化词义数据，实现“一个词性一行、该词性下展示多个义项”，不应在浏览器中临时猜测词性边界。

### 释义清洗与核心释义

完整词典释义用于数据留档，核心释义用于学习页面、练习和复习。清洗时不得覆盖或删除原始释义，应从原始释义中生成一份可追溯的核心释义。

核心释义优先保留：

- 当前词书、教材或考试大纲明确要求的词义。
- 日常和现代英语中的高频义、常用搭配义。
- 能明显区分词性或用法、且学习者容易混淆的义项。
- 该学段真实可能遇到的义项；低学段优先短、具体、易懂的表达。

以下内容默认不进入核心释义，但仍保留在原始释义中：

- 作为人名、姓氏、文学或影视角色名的释义，除非该名称本身就是当前教材的目标词条。
- 作为地名、机构名、品牌名、作品名的专有名词义，除非当前词书明确收录该专名。国家、城市等教材目标词不能仅因是专有名词而删除。
- 标记为古旧、废弃、罕见、方言、历史用法的词义，例如 `<古>`、`<旧>`、`<罕>`。
- 过度专业的医学、化学、生物分类、法律、语言学、工程或计算机义项，除非词书所属学段、专业或考试需要。
- 生僻动植物品种、分类学名称，以及仅在狭窄行业使用的器具或工艺术语。
- 与其他义项基本重复、只是措辞不同的释义。
- 例句、词源、百科说明、来源备注、交叉引用和“同……”“见……”等非释义内容。
- 过去式、过去分词、复数等词形说明。这类信息应放入独立的词形字段，不与词义混排。
- 明显超出目标学段的俚语、粗俗或敏感义项；如确有教学价值，应单独标记适用年龄和使用场景。

清洗后的数量控制：

- 每个词性通常保留 1～3 个核心义项，确有必要时可增加。
- 整个词条优先控制在 3～6 个核心义项；考试词书可根据考纲保留更多熟词僻义。
- 不按固定数量机械截断，应优先保证当前词书目标义完整。
- 无法确认是否需要的义项标记为待复核，不直接进入学习页面。

例如 `bound` 的通用核心释义可整理为：

```text
adj. 必然的，肯定的；有义务的；受约束的；开往，前往
v. 跳跃；形成边界，限制
n. 界限；跳跃
```

“装订好的”“（语法要素）黏附的”等义项可根据词书目标决定是否进入核心释义；“`bind` 的过去式和过去分词”应转为词形信息。原始完整释义仍应保留，以便考试词书、专业词书或后续人工复核重新启用。

不在第一版维护“单元”字段。源文件、数据库和用户端的学习范围以“词书（年级 + 册次）”为最小单位。

## 导入与数据质量规则

- 原始 XLSX 文件不在导入过程中被修改；数据库保存导入后的规范化数据。
- 词条标识使用规范化词面：去除首尾空格、合并连续空格并转为小写。
- 同一本词书中的完全重复词条只导入一次；若同一词面有不同音标或释义，导入任务应记录冲突，等待确认后再决定保留内容。
- 音标入库前按“音标格式”统一剥离外围 `[]` 或 `/ /`；这些符号只属于展示格式，不参与音标内容比较。
- 释义入库前按“释义与词性格式”解析；换行区分词性，分号区分同词性的多个义项。
- 核心释义按“释义清洗与核心释义”生成；原始释义与核心释义必须分开保存，不能用清洗结果覆盖原文。
- 源表不得出现空单元格；缺少音标或释义时统一填写 `无`。
- `英音`、`美音`或`释义`为 `无` 时，对应字段应标记为 `PENDING_AI_ENRICHMENT`，后续由异步 Worker 调用 AI 补全，API 不同步等待该任务。
- 保留原始完整释义，并支持单独维护面向当前学段的“核心释义”。例如小学词书中 `ruler` 的核心释义可为“尺子”，而“统治者”等通用词典义项保留在完整释义中。

## 用户端词书选择

用户端按以下路径选择系统词书：

```text
学段 Tab → 年级 Tab → 词书卡
小学      → 三年级   → 人教版三年级（上）
```

词书卡至少展示教材版本、年级册次、总词数和该用户的学习进度。教材版本是词书卡的属性；当同一年级存在多个版本时，在同一年级 Tab 下并列展示对应词书卡。

用户的熟练度、学习进度、复习次数和下次复习时间必须独立于词表源数据保存，并关联到“用户 + 词书词条”；不得回写 Excel 文件。

## 数据库与启动导入

应用启动时由 API 幂等导入 `apps/api/assets/vocabulary` 中的所有 XLSX。导入程序以相对文件路径作为词书的稳定 `sourceKey`，重复启动不会重复创建词书或词书词条。

- `VocabularyBook` 保存系统词书、分类、源路径和展示名称。
- `VocabularyWord` 以规范化词面全局去重；源表中的 `无` 写入数据库时转换为 `null`，表示待补全而非真实内容。
- `VocabularyBookWord` 保存词书内的顺序和词条关联。
- `UserVocabularyBook` 记录用户已开始学习的词书及唯一默认词书。
- `UserWordProgress` 为后续熟练度、复习次数和间隔复习预留用户级进度。

## 前端词书接口

所有接口均需要登录态：

| 接口 | 用途 |
| --- | --- |
| `GET /vocabulary/system` | 返回系统词表分类与词书卡；可传 `category` 筛选。 |
| `GET /vocabulary/learning` | 返回当前用户“学习中”的词书。 |
| `GET /vocabulary/default` | 返回当前默认词书；未选择时返回 `null`。 |
| `GET /vocabulary/dashboard-words` | 返回看板待复习词与当前默认词书中的新词；可传 `newWordCount` 临时扩大新词展示数量。待复习词跨全部学习中的词书汇总。 |
| `PATCH /vocabulary/dashboard-settings` | 保存用户默认新词数量，取值为 5–40。 |
| `POST /vocabulary/words/:bookWordId/review` | 将当前用户学习中词书内的词条加入待复习。 |
| `POST /vocabulary/books/:bookId/start` | 将系统词书加入学习中并设为默认词书。 |
| `POST /vocabulary/books/:bookId/continue` | 将学习中的词书设为默认词书并更新最近学习时间。 |

前端词表抽屉保持“学习中 / 我的词表 / 系统词表”三个主 Tab。系统词表只按学习阶段或目标分类展示，不额外提供教材版本筛选；词书卡本身仍可在标题中保留必要的版本信息。

学习看板的新词数量属于用户偏好：首次默认 10 个，用户可设置为 5–40 个；“+3”仅扩大当前列表的展示数量，不改变默认设置。待复习词不随默认词书切换而清空，以便保留从不同词书加入复习的词条。

## 用户学习记录重置

账户设置中的“清理学习记录”只重置当前登录用户的学习业务数据：

- 学习计划、计划单词项及其答题记录；
- 单词学习/复习进度与动态复习排期；
- 已掌握单词；
- 用于连胜和统计的学习事件。

账号、已加入学习的词书、当前默认词书、大模型选择、密码、每日新词数量以及全局共享的 AI 阅读材料/题目缓存均保留。清理通过 `DELETE /vocabulary/learning-records` 在数据库事务中完成，Web 必须在执行前展示不可撤销的二次确认。
