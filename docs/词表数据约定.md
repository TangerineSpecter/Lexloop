# 内置词表数据约定

本文约定 Lexloop 内置词表的源文件组织、导入规则和用户端呈现方式。词表的原始 Excel 文件只用于导入；运行时词条、词书和学习进度均以数据库为准。

## 源文件目录与命名

内置词表统一存放于 `apps/api/assets/vocabulary`，按以下层级组织：

```text
{学段}/{教材版本}/{年级}{册次}.xlsx
```

当前人教版小学英语示例：

```text
apps/api/assets/vocabulary/
└─ 小学/
   └─ 人教版/
      ├─ 三年级上.xlsx
      ├─ 三年级下.xlsx
      ├─ 四年级上.xlsx
      ├─ 四年级下.xlsx
      ├─ 五年级上.xlsx
      ├─ 五年级下.xlsx
      ├─ 六年级上.xlsx
      └─ 六年级下.xlsx
```

- 学段示例：`小学`、`初中`、`高中`、`大学`、`考试`。
- 教材版本示例：`人教版`、`外研版`。考试词书可使用考试名称作为此层级，例如 `CET-4`。
- 文件名仅使用“年级 + 上/下册”，例如 `三年级上.xlsx`；不要把已在目录中表达的信息重复写入文件名。

导入程序从目录和文件名读取词书元数据，不以人工填写的展示名称作为唯一依据。文件移动或重命名后，须同步更新导入配置或重新执行导入。

## Excel 格式

每个文件只包含一册词书，首个工作表第一行必须具有以下列：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `单词` | 是 | 单词或词组；去除首尾空格后不能为空。 |
| `英音` | 否 | 词组等没有可靠音标时可留空。 |
| `美音` | 否 | 词组等没有可靠音标时可留空。 |
| `释义` | 是 | 原始释义；暂缺时可填写 `无`，导入后作为待补充内容处理。 |

不在第一版维护“单元”字段。源文件、数据库和用户端的学习范围以“词书（年级 + 册次）”为最小单位。

## 导入与数据质量规则

- 原始 XLSX 文件不在导入过程中被修改；数据库保存导入后的规范化数据。
- 词条标识使用规范化词面：去除首尾空格、合并连续空格并转为小写。
- 同一本词书中的完全重复词条只导入一次；若同一词面有不同音标或释义，导入任务应记录冲突，等待确认后再决定保留内容。
- 音标为空不会阻止导入。
- `释义` 为 `无` 时，导入结果的释义状态应为 `PENDING_AI_ENRICHMENT`，后续由异步 Worker 调用 AI 补全，API 不同步等待该任务。
- 保留原始完整释义，并支持单独维护面向当前学段的“核心释义”。例如小学词书中 `ruler` 的核心释义可为“尺子”，而“统治者”等通用词典义项保留在完整释义中。

## 用户端词书选择

用户端按以下路径选择系统词书：

```text
学段 Tab → 年级 Tab → 词书卡
小学      → 三年级   → 人教版三年级（上）
```

词书卡至少展示教材版本、年级册次、总词数和该用户的学习进度。教材版本是词书卡的属性；当同一年级存在多个版本时，在同一年级 Tab 下并列展示对应词书卡。

用户的熟练度、学习进度、复习次数和下次复习时间必须独立于词表源数据保存，并关联到“用户 + 词书词条”；不得回写 Excel 文件。
